# VENTURE Evidence Over Bureaucracy Principle

**Status:** Permanent governance principle

Documentation, process, tests, checkpoints, approvals and reports exist to improve VENTURE—not to create ceremony.

A process item is valuable only when it materially helps at least one of:

- prevent defects;
- protect data/security/trust;
- preserve continuity;
- reduce debugging loops;
- save Claude usage;
- save Product Owner time;
- improve acceptance evidence;
- improve release reliability;
- retain important team learning;
- reduce future rediscovery.

If a rule or document repeatedly adds work without providing one of those benefits, simplify, automate, merge or remove it.

Do not confuse:

- more documentation with more quality;
- more tests with better evidence;
- more agents with faster delivery;
- longer prompts with clearer prompts;
- more approvals with safer architecture.

The preferred system is the **minimum process that reliably produces maximum accepted outcome**.

When evidence and bureaucracy conflict, preserve the evidence and simplify the bureaucracy.

**PROCESS IS A TOOL, NOT THE PRODUCT.**
